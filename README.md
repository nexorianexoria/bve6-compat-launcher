# BVE5 Vehicle Compatibility for BVE6

**Ver.0.29a3 試験版**。BVE Trainsimの路線・車両を選び、BVE5またはBVE6で起動する非公式ランチャーです。BVE6で従来の32ビットATSプラグインを使用するための互換機能を含みます。

## ダウンロード

[導入用EXEをダウンロード](https://raw.githubusercontent.com/v7p2xr/bve6-compat-launcher/main/downloads/0.29a3/BVE6Launcher-Setup.exe)

EXEを開き、利用規約、導入先、ショートカットなどを確認して進めてください。管理者権限の確認が表示されます。実行ファイルは電子署名されていないため、Windowsで発行元不明の警告が出る場合があります。

## 必要なものと対応状況

64ビット版Windowsと、別途入手したBVE Trainsim、路線・車両が必要です。車両によってBveEXやMotorMasterなどを別途用意する必要があります。それぞれの配布元の条件に従ってください。

すべての車両、ATSプラグイン、音声や運転機能に対応しているわけではありません。TM10000の一部車両ではBveEX設定の引き継ぎを利用者が確認しました。BVE5のメモリ不足やBVE6の描画中の異常終了については未解決の記録があります。

本バージョンのインストーラーと自動更新は、隔離した環境での処理確認を行いました。実際の別PCでの操作、すべての車両での動作は未確認です。問題が発生する可能性があるため、必要なデータをバックアップしてお使いください。

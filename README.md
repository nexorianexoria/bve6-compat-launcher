# BVE5 Vehicle Compatibility for BVE6 / BVE6互換ランチャー

**最新版：Ver.0.29b14（インストーラー／ポータブルZIP版）**

**先行公開：Ver.0.29b15（インストーラー／ポータブルZIP）。** 2026年11月14日の検証で、b15候補の一部EXEにMicrosoft Defenderの`Trojan:Win32/Wacatac.H!ml`検出がありました。誤検知かどうかは未判定です。検出を回避する操作は案内しません。b15の自動更新はまだ公開していません。詳しくは[安全性検証結果](SECURITY_REVIEW_0.29b15.md)をご覧ください。

BVE Trainsim 5/6向けの路線・車両を選び、BVE5またはBVE6を起動する非公式ランチャーです。BVE6で従来の32ビット版ATSプラグインを利用するための互換機能を搭載しています。

## b15先行公開版の変更点

起動モニターへのBVEメイン画面の再配置処理を改善しました。また、BVE6互換起動でバックグラウンド音声を使用する場合に、事前確認に合格した24/32bit整数PCM WAVを作業コピー内でIEEE float32 WAVへ変換する処理と、DSOALログの読み取り専用診断を追加しました。元のBVE本体、路線、車両、ATS、WAVは変更しない設計です。

実機で2つのシナリオの起動・終了を確認しましたが、全ての車両の音声再生やFPS向上は確認していません。**この先行公開版はb14の配布版やインストール済みアプリへの自動更新には反映されません。**

## b14の改善

別のウィンドウを操作してもBVEの音声を維持できるオプションを追加しました。BVE5・BVE6用の同梱音声ライブラリ（DSOAL）を使用します。設定の初期値はオフ。元のBVE本体を改変しません。

詳しくは [Ver.0.29b14リリースノート](RELEASE_NOTES_0.29b14_PUBLIC.md) をご覧ください。

## b13の改善
BVE運転画面の最前面固定（チェックボックス、初期設定オフ）を追加し、車両一覧のパネル画像処理と32ビットATS互換処理を軽量化しました。バックグラウンド音声は未対応です。

詳しくは [Ver.0.29b13リリースノート](RELEASE_NOTES_0.29b13_PUBLIC.md) をご覧ください。

## b11の改善

設定画面に「BVEの画面・軽量化・入力デバイス設定」を追加しました。BVEを起動せずに、ウィンドウサイズ、起動先モニター、描画距離・フィルター、追加入力デバイスを変更できます。モニター名はWindowsに登録された名前と解像度・リフレッシュレート（Hz）を表示します（BVEの実測FPSではありません）。

追加入力デバイスはチェック式一覧から選択し、「プロパティー…」からNumerousControllerInterfaceのマスコン有効／無効・既存プロファイルを設定できます。個別設定に未対応のプラグインはBVE本体側で設定してください。

BVE起動中は設定を保存できません。保存時には元の設定ファイルをバックアップします。軽量化設定のFPS改善は路線・車両により異なり、保証するものではありません。

詳しくは [Ver.0.29b11リリースノート](RELEASE_NOTES_0.29b11_PUBLIC.md) をご覧ください。

## b9の改善

タスクバーのピン留め用アプリ識別子を統一し、更新後も固定の起動用ファイルを使用します。ルート設定の「他の車両から選ぶ」から通常の画像付き車両一覧を開けます。

## b8の修正

b7の配布時に、修正前の実行ファイルが混入していた問題を解消しました。b7で開発した「ルート設定」、画像付きの車両候補、ルート名の保存などが正しく反映された版です。

詳しくは [Ver.0.29b8リリースノート](RELEASE_NOTES_0.29b8_PUBLIC.md) をご覧ください。

## b7の改善

「ルート設定」で路線と車両の候補を個別に選べます。車両側は通常画面と同じ画像付きカード一覧になり、候補の「重み」は表示しません。
設定で「ルート名を自分用に設定」をオンにすると、ルートの表示名を「テスト1」など自分用に保存できます。元データは変更しません。

詳しくは [Ver.0.29b7リリースノート](RELEASE_NOTES_0.29b7_PUBLIC.md) をご覧ください。

## b6の改善

選択中のシナリオにある路線・車両のランダム候補を確認し、それぞれ独立して選択できます。シナリオを選択するまでは詳細選択ボタンは無効です。設定画面には、配布サイトへの移動、更新履歴、手動更新確認を追加しました。

詳しくは [Ver.0.29b6リリースノート](RELEASE_NOTES_0.29b6_PUBLIC.md) をご覧ください。

## b5で実施した負荷軽減

BVE運転中のランチャー負荷を抑えるとともに、32ビットATSの互換ブリッジを最適化しました。毎フレームの文字列・配列変換で一時メモリ割り当てを減らし、受信用イベントを再利用して運転中の診断ファイル出力を軽減しています。通常使用では開発用の詳細性能計測を無効にしました。

ただし、実際のBVEでのFPS向上は確認できていません。すべての車両・ATSプラグインとの互換性も保証していません。詳しくは [Ver.0.29b5リリースノート](RELEASE_NOTES_0.29b5_PUBLIC.md) をご覧ください。

## 必要なもの

- 64ビット版Windows、.NET Framework 4.8
- BVE Trainsim 5または6本体
- 別途入手した路線・車両データ
- 車両により [BveEX](https://bveex.okaoka-depot.com/)・MotorMaster等

BVE本体、路線・車両、外部ATS・BveEX・MotorMasterは同梱していません。各配布元の利用条件をご確認ください。

## 旧版インストール・自動更新について

**インストール済みの古い版は、アプリ起動時に更新情報を確認します。** 新しい版がある場合だけ、更新内容と「更新する／今はしない」の確認画面が表示されます。インストール版では更新後の自動起動も選べます。最新版の場合は確認ダイアログは出ません。ポータブル版では新しい版がある場合、最新版のダウンロードページを案内します。

過去のリリースの配布ファイルは残してあります。旧版からのアップデートでは既存のインストール先に新バージョンを配置します。ポータブル版は別フォルダーで利用できます。

# BVE5 Vehicle Compatibility for BVE6

Ver.0.29a4。BVE Trainsimの路線と車両を選び、BVE5またはBVE6を起動する非公式ランチャーです。BVE6で32ビットATSプラグインを使うための互換機能を含みます。

## ダウンロード

[導入用EXEをダウンロード](https://raw.githubusercontent.com/nexorianexoria/bve6-compat-launcher/main/downloads/0.29a4/BVE6Launcher-Setup.exe)

EXEを開き、利用規約に同意したうえでインストール先などを選んでください。インターネット接続が必要です。管理者権限の確認が表示されます。EXEには電子署名がないため、Windowsに発行元不明の警告が表示される場合があります。

## 必要なものと対応状況

64ビット版Windows、別途入手したBVE Trainsimと路線・車両が必要です。車両によってはBveEXやMotorMasterなども必要です。それぞれの配布元の条件に従ってください。

路線・車両一覧はフォルダーごとに表示します。シナリオの路線・車両のランダム指定に対応しています。BVE5・BVE6の標準的な場所を自動検出し、見つからない場合は手動で指定できます。起動時には更新を確認し、新しい版があれば更新するかを尋ねます。

すべての車両、ATSプラグイン、音声や運転機能への対応を保証するものではありません。0.29a4のインストール・更新・実際の走行は未確認のため、公開前に別のPCなどで確認してください。必要なデータはバックアップしてください。

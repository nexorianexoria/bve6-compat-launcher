# BVE5 Vehicle Compatibility for BVE6 / BVE6互換ランチャー

**最新版：Ver.0.29b5（ポータブルZIP版）**

BVE Trainsim 5/6向けの路線・車両を選び、BVE5またはBVE6を起動する非公式ランチャーです。BVE6で従来の32ビット版ATSプラグインを利用するための互換機能を搭載しています。

## ダウンロード

**[Ver.0.29b5 最新版ダウンロード](https://github.com/nexorianexoria/bve6-compat-launcher/releases/latest)**

Releasesの「Assets」から BVE6Launcher-0.29b5-Portable.zip をダウンロードしてください。今回のb5はインストーラーではなくZIP版です。

1. ZIPを右クリックして「すべて展開」してください。
2. 展開先の BVE6互換ランチャー.exe をダブルクリックしてください。bridge フォルダーは移動・削除しないでください。
3. シナリオフォルダーとBVE本体の場所を確認し、路線と車両を選びます。
4. 「BVE6 互換起動」「BVE6 通常起動」「BVE5 通常起動」を選びます。

[旧版のダウンロード](https://github.com/nexorianexoria/bve6-compat-launcher/releases)

## b5の改善

BVE運転中のランチャー負荷を抑えるとともに、32ビットATSの互換ブリッジを最適化しました。毎フレームの文字列・配列変換で一時メモリ割り当てを減らし、受信用イベントを再利用して運転中の診断ファイル出力を軽減しています。通常使用では開発用の詳細性能計測を無効にしました。

ただし、実際のBVEでのFPS向上は確認できていません。すべての車両・ATSプラグインとの互換性も保証していません。詳しくは [Ver.0.29b5リリースノート](RELEASE_NOTES_0.29b5_PUBLIC.md) をご覧ください。

## 必要なもの

- 64ビット版Windows、.NET Framework 4.8
- BVE Trainsim 5または6本体
- 別途入手した路線・車両データ
- 車両により [BveEX](https://bveex.okaoka-depot.com/)・MotorMaster等

BVE本体、路線・車両、外部ATS・BveEX・MotorMasterは同梱していません。各配布元の利用条件をご確認ください。

## 旧版インストール・自動更新について

b5はb3/b4を上書きせず、別のフォルダーへ展開してください。既存のインストール版の自動更新用マニフェストは当面b3を指します。b5への自動更新は行わず、上記の最新版ZIPを手動で利用してください。以前のb3やb4も削除せずに残しておけます。

# BVE5 Vehicle Compatibility for BVE6 / BVE 起動ランチャー

**Ver.0.29a8** は、路線・車両を選んでBVE5またはBVE6を起動する非公式ランチャーです。BVE6で32ビット版ATSプラグインを使用するための互換機能を搭載しています。すべての車両やプラグインの動作を保証するものではありません。

## ダウンロード・導入

1. [導入用EXEをダウンロード](https://github.com/nexorianexoria/bve6-compat-launcher/releases/download/v0.29a8/BVE6Launcher-Setup.exe)します。[過去のバージョン](https://github.com/nexorianexoria/bve6-compat-launcher/releases)も利用できます。
2. EXEを開き、利用規約に同意して、インストール先やショートカットの設定を選びます。
3. 管理者権限の確認後、GitHubから必要なファイルを取得して導入します。インターネット接続と.NET Framework 4.8が必要です。

EXEは電子署名されていないため、Windowsで発行元不明の警告が表示される場合があります。以前のインストーラーでセキュリティソフトによる検出が報告されており、その原因は未特定です。脅威として検出された場合は実行せず、保護機能の除外や無効化は行わないでください。

## 必要なもの

- 64ビット版Windows
- 別途入手・インストールしたBVE Trainsim 5または6
- 別途入手した路線・車両データ
- 車両に応じて[BveEX](https://bveex.okaoka-depot.com/)や[MotorMaster](https://sites.google.com/view/fwchbve/top/bveデーター公開一覧/MotorMaster)など

BVE本体、路線・車両データ、BveEX、MotorMasterは同梱していません。それぞれの配布元の利用条件をご確認ください。

## 起動と更新

ランチャーでシナリオと必要な車両を選び、「BVE5通常起動」「BVE6通常起動」「BVE6互換起動」から選択します。互換起動では64ビットATSを直接使用するか、32ビットATSの橋渡しを試みます。

起動時にGitHubへ更新を確認し、新しい版があれば更新するか尋ねます。「はい」を選ぶと、ランチャーを終了して管理者権限の確認後に更新し、完了後は開き直します。「いいえ」を選ぶとそのまま利用でき、次回起動時に再度確認します。現行版に更新確認を無効化する設定はありません。更新時は旧版、作業データ、登録済みMotorMasterを保持する構成です。

## 動作上の注意

- すべての路線、車両、ATSプラグイン、音声、運転機能への対応は保証していません。
- BVE5でのメモリ不足やBVE6での描画中の異常終了が発生した事例があります。これらが本ソフトに起因すると確認されたものではありません。
- 導入・更新処理は隔離環境で検証しましたが、すべてのPCやデータでの動作は確認していません。必要なデータは事前にバックアップしてください。

## ログ・アンインストール・お問い合わせ

インストール版のログや作業データは、エクスプローラーのアドレス欄に `%LOCALAPPDATA%\BVE6互換ランチャー\作業データ` と入力すると開けます。ログにはファイル名や保存場所が含まれることがあります。ランチャー自身は診断ログを自動送信しませんが、共有する際は内容をご確認ください。更新確認・ダウンロード時はGitHubに接続します。

削除はWindowsのアプリ一覧から行えます。登録に失敗した場合の方法、ログの削除、残るファイルなどは[詳しい利用案内](README.txt)をご覧ください。作業データを削除するとログやMotorMasterの登録も消えます。

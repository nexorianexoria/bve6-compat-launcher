# Ver.0.29b5：性能改善候補の検証記録

## 保存済みの実走行計測

2026-11-01のBVE6運転240秒のログを再分析。描画系列が2つあるため、どちらが運転画面かは確定していません。

- 描画系列A：フレーム間隔平均31.00ms、95%点43.17ms、CPU Busy平均29.91ms、GPU Busy平均3.03ms。
- 描画系列B：フレーム間隔平均15.37ms、95%点16.50ms、CPU Busy平均14.34ms、GPU Busy平均1.26ms。
- FPS収録区間にATS本体の処理時間が5msを超えたイベントは58回。
- 系列Aでは、そのうち25回の周辺で50ms超のフレーム間隔が記録されました。
- 同じ30秒区間から無作為に選んだ比較用の時刻で500回の照合を行ったところ、平均5.7回でした。
- これは時間的な関連を示す探索的な結果であり、ATSがカクつきの原因であると確認したものではありません。計測系列が実際の運転画面かも未確定です。

詳細と再計算手順は B5_GOAL_ANALYSIS_20261101.md / AnalyzeB5Goal.py を参照してください。元データにはローカル環境の情報が含まれるため、このリポジトリには取り込みません。

## 変更した処理

32ビットATS用の64ビット橋渡しDLLに、毎フレーム256件のパネル出力を比較して記憶するコードが残っていました。しかしその比較結果も保存変数も他の処理から利用されていませんでした。

- 不要なパネル比較とハンドル比較を削除。
- ATSへの通信、返却ハンドル、パネル出力、音声出力、定期診断ログは維持。
- 32ビット模擬ATSの往復を、変更前・変更後それぞれ20,000フレーム×5回実施。
- 変更後は高い配列番号255と負の音声値も使って3,000フレームの回帰テストを両バージョンで実施。

| 項目 | 変更前 | 変更後 |
|---|---:|---:|
| 模擬ATSでのブリッジ計測平均（5回平均） | 246.02μs | 244.14μs |
| 各回の最小～最大の平均 | 218.94～268.37μs | 228.13～258.28μs |
| 往復テスト | 成功 | 成功 |
| 高番号パネル・負値の出力 | 成功 | 成功 |

**ばらつきが差より大きいため、性能向上が実証されたものではありません。** 今回の変更は未使用処理の安全な整理として扱います。実際のBVEのFPS比較はまだ行っていません。

## 次に確認すること

1. BVE運転画面とPresentMonのSwapChainAddressとの対応を、ウィンドウを手動で切り替える計測で確認。断定できない場合は保留。
2. 再現する同一路線・車両・視点で、b4とb5の描画間隔を比較。速度・描画設定やPCの状態もなるべくそろえる。
3. ATS本体の長時間処理の原因は、ATSの処理とBVE描画負荷の両面から切り分ける。第三者が配布するATS DLLを書き換えない。
4. 効果が測れなかった優先度設定変更やWindows・GPU保護設定の変更は行わない。

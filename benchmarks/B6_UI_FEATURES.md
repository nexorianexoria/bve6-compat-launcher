# 次期Ver.0.29b6向け機能試験版

**公開済みVer.0.29b5とは別の機能開発版です。現時点ではb6として公開しません。**

## 設定画面

- **配布サイトを開く**：公式GitHub Releasesの最新版へ移動。
- **更新履歴**：過去の主要バージョン（公開済みb1～b5）の内容をオフラインで表示。すべての公開履歴をGitHub Releasesから確認できる。
- **更新を確認**：既存の署名・ハッシュ確認付きアップデート処理を利用して手動確認。最新版の場合は明示、通信エラー時も明示する。起動時の自動確認は維持。
- インストーラー・アップデータおよび既存の設定項目は維持。

## シナリオの詳細選択

- メイン画面の「候補を詳しく選ぶ」から、選択中のシナリオにある`Route`と`Vehicle`の実在ファイル候補を別々に表示。
- 両方未選択の場合は、シナリオの指定どおりに起動。ランダム指定は従来どおりランダム。
- 路線だけ選択 → 車両は元のランダム・固定指定どおり。
- 車両だけ選択 → 路線は元のランダム・固定指定どおり。
- 両方選択 → 両方の選択候補で起動。
- 詳細画面からBVE6互換・BVE6通常・BVE5通常を選んで起動。
- `Route`候補がシナリオの定義外の場合は拒否。実在しない候補は起動選択一覧から省く。
- 元のシナリオや車両は編集せず、必要なときだけ作業コピーを生成。
- **対象はシナリオの`Route` / `Vehicle`に書かれたランダム候補のみ。マップファイル内部にあるランダム分岐等の解析は対象外。**

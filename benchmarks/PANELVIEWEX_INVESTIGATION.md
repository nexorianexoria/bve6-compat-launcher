# PanelViewEXウィンドウ未表示の調査（Ver.0.29b5から分岐）

## 2026-11-01の観測

- BveEX core 2.1.51225.1とPanelViewEX 1.1.0が配置されている。
- `LoadedExtensions.xml`ではPanelViewEXが有効。
- PanelViewEXログでは実在する運転台パネルとx64ネイティブDLLの読み込みを確認。
- 同じログには「fresh ordered resume is still pending」と記録されている。ただし過去のログにも同じ文があるため、これだけで失敗とは断定できない。
- 利用者は別ウィンドウが全く表示されないと報告。
- BVE6本体へ元の32bit ATSシナリオを直接渡す比較はシナリオ読み込みエラーとなり、正常な比較にはならなかった。
- ATSなしの一時コピーによる比較は、24秒間では読み込みが完了しなかったため結論なし。いずれも専用に起動したプロセスは終了させた。
- b4とb5の通常の互換起動処理にはPanelViewEX固有の処理変更は見つかっていない。原因は未確定。
- 2026-11-01の追加実機ログ（PID 19696 / 27408）では、両方ともBVE6と別の `PanelViewEX 1.01` 可視ウィンドウが存在。ユーザーはウィンドウ未表示と報告しているため、位置・サイズ・前後関係の調査を優先する。

## 今回追加した診断

- インストール済みの通常版PanelViewEXを検出した場合だけ、BVEのPIDに対応するPanelViewEXログの生成を10秒間隔で最大6分待ち、45秒後に別スレッドで読み取り専用の状態確認を行う。ログが出ない場合も終了時点の状況を記録する。
- BVE PIDが再利用されていないかを確認し、ネイティブDLLと当該プロセスの可視トップレベルウィンドウを記録する。
- 次期b6の診断では、ウィンドウ座標・サイズ・最小化・前面フォーカス・接続モニター領域も記録する。
- 記録先はその運転用の作業コピーの `PanelViewEX診断.txt`。既存の「ログ・バグ報告」から閲覧できる。
- PanelViewEXのDLL、BveEX設定、路線・車両、ATSは変更しない。新たなユーザー操作・ポップアップも出さない。
- パネルウィンドウの修復やFPS向上を確認した変更ではない。現時点で一般公開しない。

## オフライン確認

ランチャーを `dist-panel-diagnostics` にReleaseビルドし、`benchmarks/TestPanelViewDiagnostics.ps1` を実行する。
テストは架空のBveEXフォルダーを作成し、PIDの読み取り、拡張機能の検出、BVE終了済みレポートを検証する。BVE本体は起動しない。

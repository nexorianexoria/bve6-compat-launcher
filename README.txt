BVE5 Vehicle Compatibility for BVE6 — Ver.0.29b14
BVE6互換ランチャー（非公式ツール）

■ 導入方法
インストーラー版：BVE6Launcher-Setup.exeを実行し、表示される案内に従ってください。
ZIP版：ダウンロードしたZIPを右クリックして「すべて展開」を選んでください。
展開したフォルダーの「BVE6互換ランチャー.exe」をダブルクリックして起動します。
フォルダー内のファイルは移動や削除をせず、そのままお使いください。
「bridge」フォルダーを別にインストールする必要はありません。

■ 起動方法
左側でシナリオを選び、必要に応じて右側から車両を選択してください。
「BVE6 互換起動」「BVE6 通常起動」「BVE5 通常起動」から起動できます。
「ルート設定」ではシナリオに指定された路線と車両の候補を個別に選択できます。
車両の候補は、通常の車両選択と同じ画像付き一覧で表示します。
ランダムの選択比率（重み）は候補画面には表示しません。
設定の「ルート名を自分用に設定」をオンにすると、詳細選択画面でルートに名前を付けて保存できます。
保存した名前は次回以降も表示され、シナリオやマップの元ファイルは変わりません。
片方だけ選択した場合、もう片方はシナリオの指定どおりに動作します。
シナリオが未選択の場合、詳細選択ボタンは押せません。
設定画面から配布サイト、更新履歴、手動での更新確認を利用できます。
設定画面から「BVEの画面・軽量化・入力デバイス設定」を開けます。
ウィンドウサイズ、起動モニター、描画距離・フィルター、追加入力デバイスを変更できます。
モニター選択にはWindowsに登録されたモニター名、解像度、リフレッシュレート（Hz）が表示されます。
NumerousControllerInterfaceでは、マスコンの有効／無効と既存の使用プロファイルを選択できます。
BVE起動中は設定を保存できません。保存時には元の設定をバックアップします。

■ 主な変更点
Ver.0.29b11：起動前の画面・軽量化・入力デバイス設定、Windowsのモニター名・解像度・Hz表示を追加。
Ver.0.29b9：タスクバーのピン留めを維持するための修正と、ルート設定での「他の車両から選ぶ」を追加。
Ver.0.29b8：b7の配布ファイルに修正前の実行ファイルが含まれていた問題を修正。
Ver.0.29b7：詳細選択の分かりやすさ、車両パネル画像、ルート名の保存を追加。
Ver.0.29b6：路線・車両の候補選択画面、設定画面の更新機能を追加。
Ver.0.29b5：運転中の周辺処理を軽量化し、インストーラーと自動更新確認を復旧。
FPS向上やすべてのATSプラグインとの互換性は保証していません。

■ 必要なもの
64ビット版Windows、.NET Framework 4.8、BVE Trainsim本体、路線・車両データ。
BveEXやMotorMaster等が必要な場合は、各配布元から別途用意してください。
BVE本体、路線・車両、外部ATS等は同梱していません。
